# humq-sample2

Generated by [webscaf](https://github.com/kodaimura/webscaf) with the `fast-react` pattern (FastAPI + React).

## Development

```sh
make build
make up
make migrate
```

- Web: http://localhost:3000
- API: http://localhost:8000/api
- Health: http://localhost:8000/health
- MailHog: http://localhost:8025

## Commands

```sh
make logs
make logs_api
make logs_web
make ps
make check
make down
make down_volumes
```

Use production Compose settings with `ENV=prod` after configuring production secrets and database settings in the backend environment file.

```sh
make build ENV=prod
make migrate ENV=prod
make up ENV=prod
```

The backend is in `api/` and the frontend is in `web/`. Their original Makefiles remain available for framework-specific commands.
